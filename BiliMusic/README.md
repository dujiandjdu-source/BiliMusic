# BiliMusic 使用文档

## 简介

BiliMusic 是一款 Apple Music 风格的桌面音乐播放器，基于 Electron 构建。支持本地音乐播放、网易云音乐在线搜索与播放、B 站视频音轨提取播放，以及内置 B 站视频浏览。

---

## 安装

### 下载

从 [GitHub Releases](https://github.com/dujiandjdu-source/BiliMusic/releases) 下载 `BiliMusic-Setup-x.x.x.exe`（推荐安装版，支持应用内更新）或 `BiliMusic-Portable-x.x.x.exe`（便携版，无需安装）。

### 系统要求

- Windows 10 及以上（64 位）
- 网络连接（在线功能需要）

---

## 启动

运行安装版或双击便携版即可启动。启动后及每 6 小时自动检查更新；在「设置 → 关于 → 联网更新」查看状态，点击「下载更新」，下载完成后点击「退出并安装」。下载包由 electron-updater 校验 SHA-512，网络失败可重试或前往 GitHub 下载。

便携版应用内更新会启动安装版安装程序，原便携文件会保留；安装版与便携版使用相同的用户数据目录，更新不会清除音乐库、歌单和设置。旧版缺少完整更新支持，需要先手动下载本次版本。

## 功能详解

### 1. 导入音乐

支持三种方式导入音乐：

**方式一：导入本地文件**

点击顶栏 `📂 导入本地文件`，选择一个或多个音乐文件（mp3、flac、wav、ogg、m4a 等）。

> 💡 支持导入 QMC 加密文件（QQ 音乐下载的 `.qmc0` / `.qmcflac` 等），程序会自动解密。也可使用命令行工具：
> ```
> npm run qmc:decode -- <文件路径>
> ```

**方式二：粘贴链接导入**

点击设置 → 选择「从链接添加」，粘贴以下类型的链接：
- 网易云歌曲链接：`https://music.163.com/#/song?id=xxxxx`
- 网易云歌单链接：`https://music.163.com/#/playlist?id=xxxxx`
- B 站视频链接：`https://www.bilibili.com/video/BVxxxxx`
- B 站 BV 号：`BVxxxxx`

**方式三：搜索导入**

按 `Ctrl+K` 打开搜索框，可搜索：
- **云音乐**（Cloud）：搜索网易云音乐在线歌曲，直接播放
- **队列**（Queue）：在当前已导入歌曲中筛选

---

### 2. 音乐播放

| 功能 | 操作 |
|------|------|
| 播放/暂停 | 点击 ⏯ 或按 `空格` |
| 上一首/下一首 | 点击 ⏮ ⏭ 或按 `←` `→` |
| 快进/快退 5 秒 | 按 `Ctrl+←` / `Ctrl+→` |
| 调节音量 | 拖拽音量滑块或按 `↑` `↓` |
| 音量面板 | 按 `V` |
| 播放模式切换 | 点击 🔄 或按 `L`（全部循环 / 单曲循环 / 随机播放） |
| 倍速播放 | 点击速度按钮或按 `S`，支持 0.5x ~ 2x（含 Nightcore 模式） |
| 拖拽排序 | 在播放列表中长按歌曲拖动调整顺序 |

---

### 3. 播放列表

点击底部 📋 按钮打开播放列表面板：

- 查看当前队列中所有歌曲
- 点击歌曲直接播放
- 点击 ✕ 从队列移除
- 全选 / 批量删除
- 拖拽排序
- 从链接添加歌曲

音乐库与播放队列分别保存。移出队列不会删除歌曲、喜欢、收藏、歌单或应用内本地副本；清空队列后重启仍保持队列为空。
在设置的「音乐库」中可找回并播放已导入的歌曲。这里的「删除」会在确认后移除歌曲、相关收藏和歌单引用及应用内副本，原始音乐文件保持不变。
「播放全部」会按所选歌单的顺序建立播放队列。

---

### 4. 设置面板

点击顶部用户头像进入设置，包含以下标签页：

| 标签 | 功能 |
|------|------|
| 个人资料 | 修改昵称、签名 |
| B 站账号 | 扫码登录 B 站，浏览关注的 UP 主视频 |
| 音乐库 | 查看所有已导入的歌曲，重新加入播放，或确认删除 |
| 播放历史 | 最近播放、累计次数、上次播放时间、近 30 天最近常听 |
| 我喜欢 | 查看已收藏歌曲 |
| 收藏夹 | 查看已收藏歌曲 |
| 歌单 | 创建/管理歌单 |
| 关于 | 版本信息、检查更新、清除缓存 |

播放历史在音频实际开始播放时记录，暂停后继续不会重复计数，重新播放和单曲循环会计数。
「最近常听」按近 30 天的播放次数自动排序，展示最多 50 首；统计窗口最多保留最近 10,000 条播放事件，累计次数单独保存。

### 迷你播放器与托盘

侧栏点击「迷你播放器」或使用托盘右键菜单打开小窗口，可查看封面、曲名，播放/暂停、切歌、喜欢，并切换置顶。
迷你播放器控制主窗口中的同一个播放器，不会产生重复音频。
关闭主窗口会隐藏到系统托盘并继续播放；点击托盘图标或迷你播放器的「展开」恢复主窗口。
完全退出请使用托盘右键菜单「退出 BiliMusic」。系统托盘不可用时，关闭主窗口会正常退出。

### 歌词校准与桌面歌词

在设置 →「播放设置」中可导入 LRC、TTML、TXT 或 JSON 歌词，也可搜索并手动选择网易云歌曲作为歌词来源。
每首歌分别保存歌词来源、导入内容和时间偏移。正数表示歌词延后，负数表示提前（范围 ±60 秒），不改变音频和原始歌词时间。
手动选择的歌词不会被较晚返回的自动匹配覆盖。桌面歌词与主窗口使用相同的校准时间。

同一页面可打开独立透明桌面歌词，并调整置顶、位置锁定、鼠标穿透、字体、字号、歌词和翻译颜色。
开启穿透后，从播放设置关闭穿透，或使用托盘菜单「解锁桌面歌词（关闭穿透）」恢复鼠标操作。

### 全局快捷键与定时停止

播放设置允许自定义播放/暂停、上一首、下一首和收藏的全局快捷键；在其他软件中、主窗口隐藏时也可使用。
默认使用 `CommandOrControl+Alt` 配合空格、左箭头、右箭头和 F。留空禁用该操作；被占用或格式无效时提示错误并恢复原快捷键。

定时停止支持 15、30、60 分钟或当前歌曲结束后暂停。时长定时使用实际时钟，暂停播放和切歌不会重置期限；重启程序会取消定时。
选择当前歌曲结束后暂停时，手动切换到另一首会取消该项，避免意外停止后续歌曲。

### 5. B 站功能

#### 5.1 B 站登录

设置 → B 站账号 → 扫码登录。登录后可以：
- 浏览关注的 UP 主列表
- 查看 UP 主视频列表
- 一键播放视频音轨

#### 5.2 B 站视频模式

点击顶栏切换按钮进入视频模式，内置 B 站网页浏览器，可直接在应用中浏览和观看 B 站视频。

---

### 6. 歌词显示

支持以下歌词格式：

- **LRC**：基础歌词格式（`[mm:ss.xx]歌词`）
- **增强 LRC**：支持逐字动画
- **YRC**：精确时间轴歌词
- **TTML/ITT**：支持翻译、罗马音、多歌手对齐

歌词自动从以下来源匹配：
1. 本地音频文件内嵌歌词
2. 网易云音乐在线匹配
3. 同名 `.lrc` 文件

---

### 7. 歌单管理

- **创建歌单**：设置 → 歌单 → 新建，可选从当前队列/我喜欢/收藏夹导入
- **编辑歌单**：重命名、添加歌曲、移除歌曲
- **导入/导出**：支持歌单数据导入导出

## 开发者指南

### 修改与回归验证

在 `BiliMusic` 目录运行 `npm test` 执行核心逻辑回归测试；运行 `npm run check` 依次完成类型检查、回归测试和生产构建。测试不依赖在线音乐服务或登录账号。

桌面验收脚本 `tools/check-desktop.cjs` 使用 Playwright 和项目内 Electron，在独立临时资料目录验证窗口拖动、侧栏、最大化恢复、视频工具栏、版本显示、本地播放与重启恢复。运行 `node tools/check-desktop.cjs <Playwright 模块路径> [应用目录或 app.asar 路径]`；省略应用目录时检查当前生产构建。脚本不使用现有用户音乐库或登录资料。便携版打包命令会先执行完整 `check`，版本号应在构建前更新。

歌曲创建统一使用 `src/services/songFactory.ts`，显示名称规则集中在 `songMetadata.ts`，去重规则集中在 `songIdentity.ts`。修改标题时保留 `originalTitle`；B 站合集名使用 `biliVideoTitle`，避免从曲名推测合集名。网络搜索统一使用 `usePaginatedSearch`，队列变更统一经过 `useQueueState`，避免旧请求或旧队列覆盖最新状态。

自动化测试覆盖核心状态与输入边界；在线音源可用性、账号登录和安装包启动还需实际验证。

## 常见问题

### 音频处理与完整备份（1.3.0）

在「设置 → 播放设置 → 音频体验」启用 10 段均衡器、实时音量均衡或设置 0–8 秒交叉淡化。默认关闭处理；均衡器提升频段时自动留出峰值余量。音量均衡根据播放中的 RMS 平滑调节，静音段不增益，并限制最大放大；不是离线整曲 LUFS 分析。

自动交叉淡化仅用于多曲队列、非单曲循环且歌曲时长大于两倍淡化时间的情况。开启定时停止后不会提前自动切歌。暂停、定位、删除和播放失败会清理旧音轨。音量、倍速、变调和音频处理偏好会保存。

在「设置 → 歌单 → 完整备份与恢复」导出包含应用内本地音频、歌曲信息、歌词及校准、队列、喜欢、收藏、歌单、历史和偏好设置的 JSON。文件较大时生成、校验会需要更多内存与时间，请等待完成。备份在本地保存，不会自动上传。

恢复前先查看备份日期、歌曲、队列、歌单和音频数量，可取消而不修改数据。确认恢复会替换当前音乐库，成功写入后自动重新加载；失败则回滚，原始磁盘音乐文件保留。旧版「导入/导出歌单数据」仍可使用，仅处理歌单和收藏资料。

**Q: 网易云音乐无法播放？**
A: 程序使用第三方代理 API 获取音频链接，偶尔可能不稳定。可以尝试切换音质（设置中可选 标准/高品/无损/自动）。

**Q: B 站视频音轨加载失败？**
A: 尝试在设置中登录 B 站账号，部分视频需要登录后才能获取高清音轨。

**Q: 歌词没有显示？**
A: 程序会先读取音频内嵌歌词，再尝试在线匹配。如果都没有，可以手动将 `.lrc` 文件放在音频同目录下。

**Q: 如何完全卸载？**
A: 删除 exe 文件即可。如需清除数据，删除 `%APPDATA%/bili-music` 目录。
