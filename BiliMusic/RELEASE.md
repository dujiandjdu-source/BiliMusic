# BiliMusic 1.3.0

## 新增内容
- 10 段均衡器（31 Hz–16 kHz，±12 dB）、实时 RMS 音量均衡和峰值保护，默认关闭；统一播放器与频谱的音频链路，避免重复出声。
- 0–8 秒切歌交叉淡入淡出，支持手动切歌及多曲队列自动衔接；暂停、定位、删除歌曲和播放失败会清理旧音轨。开启定时停止时不提前自动切歌。
- 音量、倍速、变调偏好和音频处理设置持久化，并纳入完整备份。
- 完整备份包含歌曲信息、应用内本地音频、队列、喜欢、收藏、歌单、历史、歌词校准和偏好设置；恢复前展示预览，确认后替换并重新加载。
- 音频与音乐库信息在同一 IndexedDB 事务内恢复，写入失败回滚；拒绝重复编号、缺失音频、损坏编码及无效引用，取消预览不改动音乐库。
- 备份在用户选择的位置本地保存；GitHub 发布不包含本地音乐、缓存或个人资产。

## 验证范围
- 单元回归覆盖音频配置边界、静音门限和峰值限制，以及完整备份格式、缺失音频、大文件分块解码、失败后的重试。
- 使用真实 OfflineAudioContext 测量均衡器衰减、频段增强、关闭处理时的信号幅度及响度均衡。
- 桌面实测覆盖音轨重叠及增益包络、单一输出链路、暂停清理、自动衔接、定时停止、备份导出、取消、写入失败回滚、恢复后重载及本地音频播放。
- 音量均衡为实时 RMS 调整，不是离线整曲 LUFS 分析；自动淡入淡出适用于时长大于两倍淡化时间的多曲队列，单曲及单曲循环保留原结束语义。

# BiliMusic 1.2.0

## 新增内容
- 包含 1.1.0 的音乐库与队列分离、迷你播放器、系统托盘和播放历史功能。
- 歌词校准：手动搜索并选择歌词来源、导入歌词文件、逐曲保存 ±60 秒时间偏移；防止旧自动匹配覆盖手动歌词。
- 桌面歌词：独立透明窗口，与主窗口共用校准时间，支持置顶、锁定、鼠标穿透、字体、字号及颜色；托盘可解锁。
- 自定义全局播放、切歌和收藏快捷键，冲突时回滚；修复提示上下文反复创建导致失败提示可能循环的问题。
- 定时停止支持 15/30/60 分钟和当前歌曲结束，使用绝对期限并处理取消与手动切歌。
- 原第三方网易云搜索/歌词接口已不可用，桌面版改为原生进程请求网易云接口，并为网络请求增加超时。

## 验证范围
- 覆盖手动歌词与自动匹配竞争、过期返回、时间偏移、逐字时间同步、配置持久化、快捷键回滚和定时停止边界。
- 桌面实测覆盖歌词导入与重启恢复、透明歌词窗口、字号/颜色、原生锁定和穿透设置、解锁，以及真实系统按键控制隐藏窗口。
- 在线样本验证网易云歌词搜索、显式选择、歌词加载和来源 ID 保存。
- 后续继续实现音频处理（均衡器、切歌淡入淡出、音量均衡）与完整备份恢复。

# BiliMusic 1.1.0（本地功能验证版）

## 新增内容
- 音乐库独立于播放队列，清空队列不删除歌曲、喜欢、收藏和歌单引用；兼容旧版队列数据迁移。
- 设置增加音乐库，支持重新播放及确认删除；歌单「播放全部」按歌单顺序建立队列。
- 迷你播放器显示封面和曲名，支持播放、暂停、切歌、喜欢与置顶。
- 系统托盘支持恢复窗口、迷你播放器、播放控制和退出；关闭主窗口隐藏后继续播放。
- 最近播放记录累计次数及上次播放时间，按近 30 天播放事件自动生成最近常听。

## 验证范围
- 回归覆盖清空队列后音乐库和引用保留、并发导入、旧数据迁移、启动导入竞争、同歌单重播、历史计数及异常数据恢复。
- 桌面验收覆盖本地音频清队列后重启再播放、迷你窗口控制、置顶、关闭隐藏后音频时间继续推进及恢复主窗口。
- 其余路线图功能（歌词校准、桌面歌词、自定义全局快捷键、定时停止、音频处理和完整备份恢复）继续按优先级实现。

# BiliMusic 1.0.8

## 更新内容
- 曲名简化按通用结构和同合集共同前缀识别，支持多种分隔符、P/Track/Disc 编号与无编号分 P；保留版本名和原始标题。
- B 站合集标题去掉编号曲目后缀，歌曲标题去掉重复的合集前缀和曲目编号；原始标题保持完整。
- 修复窗口拖拽事件和视频工具栏遮挡；窗口交互验收检查实际坐标变化。
- 修复启动恢复覆盖新增歌曲，过滤异常歌词数据并明确报告本地存储失败。
- 先统一版本号再构建，确保关于页与便携包版本一致。
- 统一歌曲创建、标题清理和去重规则，简化曲名并保留原始标题与 B 站合集名。
- 修复同曲重播、网易云音质恢复、快速切歌与旧搜索请求覆盖新结果等状态问题。
- 修复并发导入重复资源与本地歌曲删除后的持久化资源清理。
- 增加核心逻辑回归测试，构建检查同时执行测试。
- 修复远程音乐缓存逻辑缺失导致的无法播放问题。
- 修复播放失败时状态仍显示播放中的问题。
- 内置 B 站视频模式使用 BrowserView 渲染。
- 收窄 Electron 响应头放宽逻辑，只作用于 B 站相关页面。
- 增加 Windows 便携版打包脚本：`npm run pack:portable`。

## 覆盖旧版本
1. 从 Git 仓库拉取最新代码。
2. 在 `BiliMusic` 目录运行 `npm install`。
3. 运行 `npm run pack:portable` 生成便携版 exe。
4. 用新的 exe 替换旧版本程序。
